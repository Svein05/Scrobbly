Lista de Comandos

/link <username>
Vincula tu cuenta de Discord con Last.fm para empezar a usar el bot.
/unlink
Desvincula tu cuenta y borra tus datos guardados de forma segura.
/np [usuario]
Muestra la canción actual. Si mencionas a alguien, muestra su canción.
/linkcanal <canal>
(Admins) Configura el canal para actualizaciones automáticas del ranking.
/sync
(Admins) Actualiza el leaderboard manualmente al instante.
